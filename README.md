# Addon — New Disc

Аддон для Minecraft Bedrock, который добавляет 14 крафтовых музыкальных дисков.

## Что добавлено
- 14 предметов-дисков (`BR/items`)
- 14 рецептов крафта (`BR/recipes`)
- `BR/manifest.json` для Behavior Pack
- `RP/manifest.json`, `RP/textures/item_texture.json`, `RP/sounds.json` для Resource Pack

## Установка
1. Скопируйте папки `BR` и `RP` в директории паков Minecraft Bedrock.
2. Включите оба пака в мире (Behavior + Resource).
3. Добавьте свои аудиофайлы `.ogg` в `RP/sounds/music_discs/` с именами из `RP/sounds.json`.

Без `.ogg` файлов диски будут создаваться, но звук проигрываться не будет.
